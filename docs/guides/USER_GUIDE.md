# AI HOT 使用说明

> 文档文件：`docs/guides/USER_GUIDE.md` · 最近更新：2026-09-09

AI HOT 是 Garena 投资部专用的 AI 新闻看板，汇总 AIHOT 与公众号等信源，提供全部动态、公司与产品全景、热点排行和日报/周报。新闻摘要与部分结构化字段由 AI 生成，重要信息请以原文为准。

当前以本地 Next.js 版本为准，旧 CloudBase 页面不再使用。本地服务启动后，浏览器打开 `http://localhost:3000`。

如果服务尚未启动，先看[附录：Windows 本地使用](#附录windows-本地使用)。

## 第一次使用

1. 确认本地服务已经启动，然后打开 `http://localhost:3000`。
2. 首页默认进入“全部 AI 动态”；左侧第二栏是“公司与产品全景”，其后是“热点榜”和“AI 日报”。手机端先点左上角菜单按钮打开导航。
3. 使用搜索、分类、标签和来源筛选缩小范围。
4. 点击新闻标题，在新标签页查看原文。

需要完整浏览和检索时使用“全部 AI 动态”；需要按主体研究公司、产品、团队与融资信息时进入“公司与产品全景”。

## 页面导航

| 页面 | 适合查看 |
|------|----------|
| 全部 AI 动态 | AI HOT 实时信息流与公众号快照合并后的完整列表 |
| 公司与产品全景 | 从全部资讯中提取的公司、产品、业务、团队、融资与原文证据 |
| 热点榜 | 过去 48 小时的热门 AI 事件和相关信源 |
| AI 日报 | 按日期阅读 AIHOT 每日上午八点发布的成品日报，或切换到本站周报 |
| 设置 | 配置本地采集和 AI 加工所需的 API Key |

切换页面后，已经使用过的搜索词和筛选条件会保留。需要重新浏览全部内容时，记得清空搜索框和标签。

### 全部 AI 动态

这里是网站首页，合并 AI HOT 实时数据与本地快照，公众号文章也会出现在列表中。页面按日期展示全部内容，并提供六类新闻分类、标签、来源和搜索筛选。实时接口暂时不可用时，页面会继续展示已有快照，并显示提示。

### 公司与产品全景

这是独立的公司情报页面。顶部展示公司、产品和已处理来源数量；可按公司、产品、业务或团队搜索，也可按行业和国家/地区筛选。桌面端使用固定表头与公司首列的宽表，手机端自动改为公司档案卡片。字段旁的来源标记可直接打开相关原文。

### 热点榜

热点榜按热度排列过去 48 小时的事件。标签含义：

- “爆”：短时间内出现密集报道或讨论。
- “新”：事件首次出现约 6 小时以内。
- “发酵中”：相关信源仍在增加。

点击每条热点右侧的热度数字，可以展开参与计算的信源名单。

### AI 日报

AI 日报有“日报”和“周报”两个入口。日报直接同步 AIHOT 每日上午八点发布的成品，本站每日十点任务完成后更新；周报继续由本站新闻归档生成。先在左侧日期列表选择一期，右侧会显示正文，也可通过正文中的入口打开 AIHOT 当期日报。

### 设置

设置页用于配置采集和 AI 加工所需的密钥。页面通过 `127.0.0.1:9731` 的本地设置服务保存 `.env`；连接测试、下载和复制配置也在本机完成。

## 搜索与筛选

### 搜索

搜索框会匹配以下内容：

- 新闻标题和摘要
- 来源名称与公众号名称
- 原文 URL

搜索不区分英文大小写。没有结果时，先清空标签和来源筛选，再缩短关键词。

### 新闻分类

“全部 AI 动态”使用以下六类新闻分类：

- 融资动态
- 深度访谈
- 产品和模型发布
- 论文研究
- 大厂动态
- 泛行业新闻

切换分类会清空上一分类的维度标签，避免不同类别的筛选条件互相影响。

### 标签筛选

部分分类会显示行业、地区、访谈对象、发布主体、公司或变动类型等标签。同一维度可以选择多个值，匹配其中任一值即可；不同维度同时生效。

### 来源筛选

来源分为“一手信源”“资讯”“推文”“公众号”。系统依据来源名称和域名自动判断，个别条目可能出现分类偏差。公众号范围同时包含 Manus 采集条目与 AI HOT 开放 API 中的公众号内容。

## 阅读新闻与核对原文

- 点击标题会在新标签页打开原文。
- 摘要用于快速判断文章是否值得阅读，引用、金额、日期和公司信息请回到原文核对。
- 页面时间统一使用北京时间。
- 部分文章会显示评分和分类标签，这些字段用于排序与筛选，不构成投资或业务判断依据。
- 原网站删除文章、限制地区访问或调整链接后，原文可能暂时无法打开。

## 查看融资动态

在“全部 AI 动态”中选择“融资动态”，页面会优先显示公司维度表格。表格通常覆盖最近一周的融资报道。

使用方法：

1. 用所属行业、公司类型和国家/地区标签筛选公司。
2. 搜索公司、产品、行业或投资人名称。
3. 表格较宽时横向滚动；公司名称列会固定在左侧，方便对照。
4. 点击“来源”列中的标题查看报道原文。

字段旁的“搜”标记表示该内容经过联网搜索补全。短横线表示当前资料中没有可靠值。表格字段由 AI 抽取和整理，涉及融资金额、估值与投资人时应查看来源文章。

## 查看公司与产品全景

“公司与产品全景”覆盖全部新闻类别，不限于融资报道。页面字段包括公司、代表产品、成立时间、国家/地区、主营业务、团队、历史投资人、累计融资、最新估值和相关新闻。

如果页面显示“等待首次生成”，表示前端与表格结构已就绪，但模型 API 尚未生成正式公司数据。配置模型后运行 overview 阶段，数据会在校验通过后写入页面；旧的有效公司库不会被空结果覆盖。

## 数据更新时间与异常提示

- AI HOT 实时信息来自开放 API；公众号内容由 Manus 采集后写入快照。
- 实时接口异常时，页面会回退到最近一次快照。
- 静态快照需要经过采集和构建，页面日期可能晚于新闻网站的最新日期。
- 某个公众号当天没有文章或采集失败时，该来源可能暂时缺席，不影响其他来源继续展示。
- AI 摘要、分类和融资字段可能有遗漏或误判，原文始终是核对依据。

## 常见问题

### 页面显示“无匹配内容”

清空搜索框，切回“全部”分类，并取消标签与来源筛选。切换页面时筛选状态会保留，这通常是最常见的原因。

### 热点榜加载失败

热点榜依赖实时接口。稍后刷新页面；其他页面仍可使用已有快照。

### 融资动态没有显示表格

融资表格数据尚未生成或当前没有公司记录时，页面会回退为普通新闻卡片。也可以清空筛选，确认是否因条件过窄而没有结果。

### 设置页提示“本地设置服务离线”

在项目目录打开另一个 PowerShell 窗口，运行：

```powershell
node scripts/settings-server.mjs
```

服务启动后切回浏览器，页面会重新检测连接。

### LLM 连接测试失败

检查 LLM API Key、Base URL 和模型名是否属于同一个服务商。Base URL 留空时使用项目默认地址。

### 清空设置表单后，`.env` 中的值还在

“清空表单”只删除浏览器中记住的输入，不会修改已经保存的 `.env`。需要删除本地配置时，请编辑项目根目录的 `.env`。

## 附录：Windows 本地使用

### 准备环境

- Node.js 22.13.0 或更高版本
- 已下载的 AI HOT 项目目录

首次使用时，在包含 `package.json` 和 `scripts/` 的项目目录打开 PowerShell：

```powershell
npm install
$env:WRANGLER_LOG_PATH = ".wrangler/wrangler.log"
npx vinext dev
```

浏览器打开 `http://localhost:3000`。

需要使用设置页保存 API Key 时，再开一个 PowerShell 窗口：

```powershell
node scripts/settings-server.mjs
```

设置服务只监听 `127.0.0.1:9731`。保存后，密钥会写入项目根目录的 `.env`，本地脚本下次运行时读取该文件。

### 设置项说明

| 设置项 | 用途 |
|--------|------|
| Manus API Key | 采集公众号文章 |
| LLM API Key | 生成摘要、分类和标签 |
| Tavily API Key | 补全融资表格缺失字段，可不填写 |
| LLM Base URL | 使用其他 OpenAI 兼容服务时填写 |
| LLM 模型名 | 指定摘要与标签所用模型 |
| Manus Agent Profile | 选择 Manus 执行档位 |

填写 LLM API Key 后，可以先点“测试 LLM 连接”。确认成功后再保存到本地 `.env`。

### 密钥安全

- `.env` 已被 Git 忽略，仍需确认它没有进入提交列表。
- 不要在截图、聊天记录或 Issue 中粘贴完整密钥。
- 设置页只连接本机的设置服务，不会把 `.env` 内容写入新闻页面。
- “下载 `.env`”和“复制 `.env` 内容”会包含当前表单值，使用后妥善保管文件与剪贴板内容。
