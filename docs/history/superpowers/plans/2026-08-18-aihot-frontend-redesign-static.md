# AI HOT 前端改造方案（静态 HTML 快照版）

> **技术路线**：继续沿用 `templates/index.template.html` + `scripts/build_snapshot.py` 生成纯静态 HTML，不引入 Next.js SPA。

## 1. 设计目标

- 将现有深色三栏布局整体切换为参考图所示的浅色风格。
- 左侧主导航仅保留四个一级选项：精选、全部 AI 动态、热点榜、AI 日报。
- 收藏功能作为左侧导航的一项，使用浏览器 `localStorage` 持久化。
- 右侧内容区上方放置六类分类标签：全部、模型、产品、行业、论文、教程、观点。
- 实现精选、热点榜、全部 AI 动态、AI 日报/周报四个模块。

## 2. 整体视觉规范（从参考图提取）

```css
:root {
  --bg: #f7f8fa;              /* 页面背景 */
  --surface: #ffffff;          /* 卡片/导航背景 */

  --muted: #64748b;            /* 次要文字 */
  --border: #e2e8f0;           /* 边框 */
  --accent: #0f766e;           /* 主品牌青绿 */
  --accent-light: #e0f2f1;     /* 导航选中背景 */
  --accent-hover: #ccfbf1;     /* 导航悬停背景 */
  --shadow: 0 1px 3px rgba(0,0,0,0.05); /* 卡片阴影 */

```

- 背景：浅灰 `#f7f8fa`
- 卡片：白底 `#ffffff`，细边框，轻微阴影
- 左侧导航：白底，选中项青绿背景，悬停浅青绿
- 分类标签：默认灰底，选中/悬停青绿
- 热点榜排名：第 1 名红色、第 2 名橙色、第 3 名黄色

## 4. 左侧导航

四个一级选项（图标 + 文字）：

| 图标 | 文字 | 对应 view |
|------|------|-----------|
| 闪电 | 精选 | featured |
| 列表 | 全部 AI 动态 | all |
| 火焰 | 热点榜 | hot |
| 日历 | AI 日报 | daily |
| 书签 | 收藏 | fav |

- 选中态：青绿背景 `#e0f2f1`，青绿文字，左侧 4px 青绿色条。
- 悬停态：浅青绿背景 `#ccfbf1`。
- 当前态与选中态一致。

## 5. 分类标签栏

右侧内容区上方统一展示：

```
全部 | 模型 | 产品 | 行业 | 论文 | 教程 | 观点
```

- 在精选、全部 AI 动态、AI 日报（内容内）模块中均按这六类过滤。
- 在热点榜模块中，分类标签用于过滤热点事件所属分类。
- 点击后仅展示该分类内容，同一分类内按发布时间戳倒序排列。
- 保留当前筛选状态（URL hash 或 local state）。

## 6. 模块设计

### 6.1 精选模块（Featured）

- 默认展示全部精选，按发布时间倒序。
- 顶部分类标签过滤。
- 每条新闻展示：分类标签、标题、摘要、来源、发布时间、AI 评分、原文链接。
- 列表/卡片形式（参考图：左侧时间轴 + 右侧卡片）。

### 6.2 热点榜模块（Hot）

- 调用 AI HOT API `/api/v1/hot-topics`（或后端热度接口）。
- 按热度得分从高到低排序。
- 前三名高亮展示。
- 每条展示：标题、热度值/排名、来源、发布时间、原文链接。
- 支持按分类标签过滤。

### 6.3 全部 AI 动态模块（All）

- 展示由 LLM 分类和打好标签的 AI 新闻。
- 若分类尚未完成，先展示占位结构。
- 支持按标签云/列表筛选。
- 调用 AI HOT API 获取数据。

### 6.4 AI 日报/周报模块（Daily）

- 仅保留「日报」和「周报」两种粒度，去除月报。
- 左侧按月份组织，每个月下列出该月所有日报/周报入口。
- 右侧展示选中日报/周报内容。
- 日报/周报正文通过调用 AI HOT API 爬取。
- 每条新闻按列表/条目形式展示，不使用卡片。

## 7. 数据层

静态 HTML 中内嵌 `const DATA = {...}`，包含：

```ts
interface SnapshotData {
  featured: Item[];      // 精选列表
  hot: HotItem[];        // 热点榜
  all: Item[];           // 全部 AI 动态
  daily: DailyView;      // 日报/周报数据
  categories: string[];  // 六类分类
  generatedAt: string;
}
```

`scripts/build_snapshot.py` 改造：
- 新增 `fetch_hot()` 抓取热点榜。
- 新增 `fetch_all()` 抓取全部 AI 动态。
- 新增 `fetch_daily()` 抓取日报/周报。
- 将四类数据合并输出到 `DATA`。

## 8. 收藏功能

- 使用浏览器 `localStorage` 持久化。
- 收藏入口在左侧导航。
- 收藏视图展示用户收藏的新闻列表。

## 9. 构建与部署

1. 修改 `templates/index.template.html`（浅色主题 + 新布局 + 模块 JS）。
2. 修改 `scripts/build_snapshot.py`（抓取四类数据）。
3. 运行 `python scripts/build_snapshot.py --no-tags` 生成 `public/index.html`。
4. 运行 `npm run build` 生成 `dist/client/`。
5. 本地用静态服务器验证。

## 10. 验收标准

- 浏览器强刷后显示浅色风格。
- 左侧导航、分类栏、热点榜、全部 AI 动态、日报/周报与参考图一致。
- 分类筛选保留当前状态。
- 收藏功能可在浏览器内持久化。
