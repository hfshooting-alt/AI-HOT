## 已修复

1. Manus 单条畸形字段可能中断回收，例如 URL 是数组、时间文字是数字。现在逐条隔离，后续有效文章继续核验。
2. 最终 articles/source_audits 结构异常可能覆盖此前进度回收成果。现在保留已核实文章，状态明确为 partial、覆盖未确认；普通最终 JSON 也可提供候选，但不冒充结构化完成结果。
3. 公司链接发现可能回显两条原新闻链接，将第三条新资料页挤出两页读取上限。现在优先读取非原新闻链接，仍保留每主体两页、每日模型请求限制；链接优先级不代表官网身份已经核实。今日 TypeSafeAI 发现返回官网但未读取，属于这一故障形态。
4. 公司资料补全按 ISO 字符串排序，不同 UTC 偏移可能打乱最新优先。统一比较真实时间；公司与文章旧的无时区时间按北京时间解释，显式偏移保持正确。
5. 待归属产品没有纳入旧记录对比，缓存重放也会刷新资料更新时间。现覆盖公司、待归属、排除记录，资料未变化时保持原更新时间。
