# 新分类标签体系接入（融资动态/深度访谈/产品和模型发布/论文研究/大厂动态/泛行业新闻）

## 一、概述

将精选与全部AI动态两个页面的分类体系从旧六版块（模型发布/更新、产品发布/更新、AI泛娱乐新闻、行业动态、论文研究、技巧与观点）替换为新 6 类体系，并增加每类内的双维度标签下拉筛选。

**用户核心问题的答案：AI HOT API 返回的新闻没有打好新体系标签。**
- AI HOT API 条目：仅 5 种英文粗分类（ai-models / ai-products / industry / paper / tip），经 `normalizeCategory` 归一化为旧六版块，**无两级标签**（`classification: null`）
- Manus 公众号条目：已按 `config/taxonomy.json` 打好完整新体系标签，存于 `classification` 字段
- **好消息**：`config/taxonomy.json` 已定义与新需求完全一致的体系；后端 LLM 打标链路（`build_snapshot.py` 的 `tag_finalized_days` → `tag_news.tag_items`，DeepSeek + 缓存 + 降级）已存在，只是**只覆盖"已定稿日"条目，且前端从未消费 classification**

## 二、现状分析（探索结论）

### 数据链路

```
AI HOT API (aihot.virxact.com/api/public/items)     本地 Manus 流水线
  │ category: 英文粗分类(5种)                         │ classification: {category: id, tags: {dim: id}}
  ▼                                                   ▼
build_snapshot.py: 抓取 + 合并 + 归档 upsert
  ▼
tag_finalized_days()：仅对【已定稿日】缺 classification 的条目批量 LLM 打标
  │（脚本 scripts/build_snapshot.py L340-370；缓存 tag_cache.json；无 API key 静默跳过）
  ▼
build_item()：category 归一化旧六版块 + classification 经 to_display() 转中文 label 结构
  ▼
snapshot.json → 前端 loadSnapshot（精选/全部动态的快照池）
实时流 /api/all、/api/featured → 直接代理上游（条目无 classification，category 已归一化旧六版块）
```

## 三、修改方案

### A. 后端：打标覆盖当天条目（小改，1 个函数）

**文件**：[scripts/build_snapshot.py](file:///c:/Users/wade.liu/Downloads/Garena/AI%20HOT2/AI%20HOT/ai%20hot-site/aihot-site/scripts/build_snapshot.py) `tag_finalized_days`（L340）

**问题**：目前只对 `finalized=True` 的日期打标 → **当天条目次日才有标签**，而"当天最值得关注的新闻"（精选页核心场景）当天全靠兜底映射，融资动态/深度访谈/大厂动态三个类目当天几乎为空。

**改动**：pending 收集去掉 `finalized` 限制（当天未定稿条目也打标）。函数更名 `tag_archive_days`（仅 main 一处调用，L796），docstring 同步说明 trade-off：

> 当天条目被下轮 upsert 整条覆盖后 classification 会丢失，但每轮构建都会重跑打标（缓存命中，零 LLM 成本），自愈。

**测试**：[tests/test_build_snapshot_manus.py](file:///c:/Users/wade.liu/Downloads/Garena/AI%20HOT2/AI%20HOT/ai%20hot-site/aihot-site/tests/test_build_snapshot_manus.py) 补 1 个用例：未定稿日的条目也被打标写回。

**数据回填**：本地重跑 `python scripts/build_snapshot.py`（需 .env 配置 `DEEPSEEK_API_KEY`），存量条目（含 aihot 历史定稿日）自动补齐 classification，snapshot.json / archive 随之更新。
