# AI HOT 用户使用说明设计

## 目标

在仓库根目录新增 `USER_GUIDE.md`，帮助普通读者快速使用本地 AI HOT 看板。文档正文聚焦浏览、搜索、筛选和原文核对；启动命令与 API Key 配置放在末尾附录。

## 目标读者

- 在 Windows 本机阅读 AI 新闻、热点和日报的普通用户。
- 需要启动项目或配置 API Key 的内部用户。

读者无需了解 Manus、归档脚本、GitHub Actions 或前端代码结构。

## 交付文件

- 新增：`USER_GUIDE.md`
- 保留：现有 `README.md`、`AGENTS.MD`、`CONTEXT.MD`、`MEMORY.MD`
- 不修改代码、新闻数据、快照和配置文件。

## 内容结构

1. 产品用途与本地访问地址。
2. 精选、全部 AI 动态、热点榜、AI 日报、设置五个入口。
3. 搜索、六类新闻分类、维度标签和来源筛选。
4. 融资动态表格、横向滚动、来源链接与“搜”标记。
5. 北京时间、实时接口与静态快照、AI 摘要核对提示。
6. 无匹配内容、数据未更新、设置服务离线等常见问题。
7. Windows 本地启动与 API Key 配置附录。

## 内容边界

- 明确当前以本地 Next.js 版本为准，旧 CloudBase 页面不再使用。
- 写入 localhost 地址和界面中实际存在的标签。
- 说明公众号内容来自 Manus，其他动态来自 AI HOT 开放 API。
- 提醒用户点击标题或融资表格“来源”列核对原文。
- 设置页通过本地设置服务写入项目根目录 `.env`。
- 本地命令兼容 Windows PowerShell，避免直接引用当前不兼容 Windows 的 `npm run dev` 环境变量前缀。
- 不提供采集、feed 晋升、快照构建、CI Secrets 同步和发布运维步骤。

## 写作要求

- 使用简洁中文和任务导向标题。
- 第一次出现的技术名词给出短说明，后文不重复解释。
- 少用粗体、宣传语和过密列表。
- 避免使用先否定 X、再强调 Y 的对照句式。
- API Key 示例不包含真实密钥，明确提醒 `.env` 不得提交。

## 验证方式

- 对照 `Sidebar.tsx`、各视图组件和 `SettingsView.tsx` 核对界面名称与行为。
- 检查文档中的仓库路径、localhost 地址和本地命令。
- 扫描旧数据、占位词、禁用句式和意外密钥。
- 运行现有 Python 与 Node 测试，确认文档提交没有影响项目。
- 暂存区和最终提交只包含设计说明与用户说明，保留现有 runner 和诊断文件状态。
