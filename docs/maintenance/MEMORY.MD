# 新闻Daily 项目维护经验

当前状态见[CONTEXT](CONTEXT.MD)，业务规则以当前架构及运行手册为准。此前整份记录保存在[历史归档](../history/2026-09-14/before-cleanup-MEMORY.MD)。

- 当前品牌新闻Daily，20个既定入口由匿名网站直采读取，权威配置仍为config/manus_sources.json。默认direct-only，full同映射；模型统一Paratera DeepSeek-V4-Pro。Manus、Tavily、AIHOT均停用，不恢复旧日报/热点/缓存回填。媒体转载页和公众号身份必须区分。
- 区分获取能力、可入窗样本和完整窗口覆盖，不把未创建任务称为抓取失败，不把失败称为零更新。
- 私有正文与诊断留在work；公开数据仅保留必要摘要、字段证据及来源。密钥不提交。
- 成功缓存按模型和提示词版本复用，不能伪装版本。改代码后不能篡改旧运行fingerprint来resume。
- 公司补全请求前在独立私有账本占位，不以候选发布成功作为计费记账条件；GitHub租约需读回确认，缓存缺失不能当作尚未花费。
- 恢复成功建议沿原checkedAt；字段证据列表仅调序不刷新profileUpdatedAt，新增事实或证据仍刷新。
- GitHub 定时为 UTC `30 1 * * *`（北京时间每天09:30）。校验本次run审计状态、event、ID、attempt及head SHA后，以created_at转北京时间最近已到达的09:30为截止点（09:30前创建取前一天），冻结此前24小时；创建时间无法可靠取得时在付费前停止。排队跨午夜及重跑不滑窗。手动默认启动时冻结rolling-24h，显式window-end与恢复沿原窗口。NEWS_COLLECTION_END贯穿采集/正文/加工/发布。相对发布时间保留原文证据，“昨天”全天例外保留，不能补造精确分钟。
- 全部文章保留合规直采及历史Manus元数据；缺正文、相关性排除或单条摘要分类失败只影响精选。公司/融资只从garenaSelected新增，空池不回填all、旧feed或demo。单条隔离与整体不可用分别处理。
- Python异常捕获隔离不了native SIGABRT；正文原生解析放每篇独立进程，限制输入/输出/时间，崩溃后其他篇继续。Actions绿色可以是成功来源降级发布，须分别核对已采集元数据、合格正文、精选及隔离数量。
- 新闻抽取不等于背景资料联网；旧completed没有字段结果时不推定已全面检索。服务器所在地不能证明公司国家。
- 先校验候选再发布；候选改动与正式数据并发变化必须重新验收。
- 离线回归不调用网络；Manus/Tavily暂停时连只读探针也不能触发真实HTTP。任何新的业务取舍必须向用户确认。
- 计划来源数、create POST数、取得taskId数和终态数分别记录。明确credit limit exceeded创建拒绝记not_created，未知429/超时仍保留unknown保护；排队未提交不能解释为站点失败。每日refresh额度只对Lite可用。
- 2026-09-22本轮0费用观察阈值是一次性授权，余额不足/创建不明/终态未确认保护仍在。9任务消耗153credits并全部确认终态，20计划来源未全启动，不能称20源验收完成。
- 公司迁移清理仅由AIHOT支撑的字段；身份映射和独立官网事实保留。审核规则中的article事实须绑定主体已保留的Manus或直采文章ID+URL，防公司重建回灌退休来源；门禁不替代干净基线重建。
- 白鲸56789的网页主标题简化但正文“原标题”精确匹配，可按同URL/时间/正文哈希独立审阅恢复；不能为此普遍放宽标题漂移门禁。机器之心数据服务引导页和导航壳不当正文，浏览器操作日志也不等于实际网页内容。
- 候选validate通过、review/promotion、Pages成功和线上JSON一致是分开的状态；749项Python与39项Node通过不能单独证明本轮已上线。该历史迁移批次37全部/11精选/11隔离/15排除；当前数量及发布状态以CONTEXT为准。

- 前端设置页已删除，配置用.env/GitHub Secrets；独立后台设置服务与CLI保留兼容，无设置UI。GitHub schedule恢复不代表Codex定时跟进恢复，真实调度不能由离线或手动运行替代。
