# 当前状态（2026-09-14）

## 已确认的产品规则

- AIHOT与Manus独立并行采集，合并去重后统一相关性、摘要分类，分别进入新闻展示与公司产品库；公司抽取不反向决定新闻分类。
- 北京时间09:30调度，窗口前一日09:30至当天09:30。Manus只按原始发送时间；“昨天”发布按前一自然日全天例外纳入，互动不续期。AIHOT按上游批次接收，不额外核验原文旧日期。
- 单条失败隔离，成功文章继续；来源部分失败披露，整体模型不可用或校验失败保留旧网页。
- 公司按最新报道排序，保留原文链接，资料更新时间单列。独立产品无公司归属时进入待核实产品，不创建人名公司。
- Manus默认严格成本控制；任何增加预算或替换来源需要先与用户确认。

## 当前证据

本地候选199篇新闻、2篇相关性排除、1篇内容不足隔离；64家公司、78项公司名下产品、17项待归属产品。公司199/199处理完成。该批仅ZFinance有1篇可用Manus文章，其他来源的未启动/止损/失败不等于永久无法获取。

源码与前端代码已推送；最新候选尚未晋升（发布后更新本段）。最近云端定时运行早于最后修复，news阶段失败；Pages代码部署成功不能替代每日数据链路验收。

## 当前工作

1. 明确信源失败原因，归档旧规则与一次性报告。
2. 候选发布入口：验证跨文件一致性、记录来源及哈希，防止修改后发布或覆盖更新的正式数据。
3. 将通过校验的候选发布，检查Pages展示；随后验收云端新窗口与增量公司更新。
