## 时间与发布口径

- 目标每天北京时间 09:30 触发，固定采集前一天 09:30（含）至当天 09:30（不含）；调度延迟不移动窗口。GitHub cron 显式使用 09:30 + Asia/Shanghai，等价于原 UTC 01:30；当前平台存在持续触发延迟。
- Manus 只按原始发送时间收录；已确认的“昨天”发布按前一自然日例外纳入，互动、评论、编辑不续期。AIHOT 先接收上游批次再处理。
- 所有阶段完成并通过候选校验后更新网页；09:30 是开始时间，网页更新时间记录实际完成时刻。页面日期与时刻按北京时间显示。
- 单条和普通单来源失败隔离，保留成功结果；整体模型不可用或发布校验失败保留旧网页。20 个新闻来源最多并发 3 个、依次获得启动机会；余额不足、停止状态不明及作业超时仍可能中断队列。
