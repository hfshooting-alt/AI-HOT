# 当前状态（2026-09-14）

## 已确认的产品规则

- AIHOT与Manus独立并行采集，合并去重后统一相关性、摘要分类，分别进入新闻展示与公司产品库；公司抽取不反向决定新闻分类。
- 北京时间09:30调度，窗口前一日09:30至当天09:30。Manus只按原始发送时间；“昨天”发布按前一自然日全天例外纳入，互动不续期。AIHOT按上游批次接收，不额外核验原文旧日期。
- 单条失败隔离，成功文章继续；来源部分失败披露，整体模型不可用或校验失败保留旧网页。
- 公司按最新报道排序，保留原文链接，资料更新时间单列。独立产品无公司归属时进入待核实产品，不创建人名公司。
- Manus默认严格成本控制；任何增加预算或替换来源需要先与用户确认。
