# Manus 逐来源发现与验收

当前配置共20个来源：14个腾讯新闻作者页、3个网易号、白鲸官网、机器之心产业页、Elsewhere。它们是对应承载站点，不等于微信公众号全量覆盖。定时保持关闭。

## 执行与费用

完整窗口流水线使用 `--incremental-discovery --source-seeds`：指令直接内联，按本次来源平台提供短路线，列表出现后逐篇核验、逐篇发送 `AIHOT_ARTICLE`，最后汇总。最多3个并发、创建至少间隔7秒、每源20 credits观察止损、创建不重试。观察止损不是服务端硬封顶，最终费用可能超出观察线；停止未确认时阻断后续创建。

收到最终JSON不等于任务已停止：生产任务释放并发名额前核实远端终态，必要时停止并回收结果。创建响应不确定或缺任务ID时持有创建锁熔断，避免未知任务仍运行时继续付费；已有真实ID但缺展示链接不丢任务。

固定窗口保持所选结束日前一天09:30（含）至结束日09:30（不含），Asia/Shanghai。只按原始发布/发送时间；“昨天”发布保留前一自然日例外。“1天前”不等于“昨天”，详情明确绝对时间优先，评论/点赞/编辑不续期。采集与投资相关性筛选分开：核验元数据进全部文章，后续模型筛选进精选，公司仅从精选新增。

## 平台路线

- 腾讯：直接渲染配置作者页，按可见图文栏目读取卡片并逐篇进入详情。匿名HTML空壳不等于没有文章，不能靠反复读取HTML或猜工具函数消耗预算。
- 网易：优先同一列表条目的标题链接与时间，再核验详情。推荐栏和其他作者不能混入。
- 白鲸：本地匿名预读最多3页列表、3篇详情，共6次请求、60秒、单响应1MiB；拒绝重定向、验证墙及非配置域名。只提供最多6个候选提示，不直接入库、不证明完整覆盖。列表add_time为相对展示，所有时间和身份仍由后续核验。
- Elsewhere：配置入口为多作者混合页，按当前可见作者链接进入elsewhere别处发生，仅收该作者。已观察到站内作者页 `/zh/elsewhere`；不能把其他作者最新文章冒充该来源。
- 机器之心：若实际显示正常产业列表，继续核验，作者缺失允许null；若只有数据服务提示且无文章列表，记 `list_blocked`。不绕过限制，也不悄悄替换成其他机构或付费入口。

## 输入输出留证

`work/manus/.../task-traces/` 保存实际create payload和任务结束后的只读详细记录。请求不含headers/key；完整响应可能含签名链接，只留私有work，CI沿用加密恢复包，不拷入公开JSON。

详细记录通过 `GET task.detail` 确认stopped后，再读取最多5页 `GET task.listMessages?verbose=true&order=asc&limit=200`。分页缺失、循环、截断如实标记；`traceComplete`只表示轨迹分页完整，不是新闻覆盖通过。工具参数不执行，工具状态不转为文章证据。网络或存储失败不改变采集、停止、重试行为。

达到费用线时先停止、回收并确认终态；仅在终态已确认后再等待最多15秒、补读一次普通结果，回收迟到checkpoint/final。迟到final走与正常final一致的身份、窗口、计数和契约校验。原失败批次的历史审计不会被重写。

## 验收等级

逐源分别记录：入口能否访问、是否取得可核验详情、窗口内文章数、是否确认分页/旧时间边界、回传/正文结果、实际观察费用和终态。模型声称complete不是独立人工覆盖证明；零篇必须区分“有边界证据的无更新”和“尚未获得文章”。历史成功样本也不等于当前窗口通过。

测试先离线验证20份实际创建请求，再做有明确任务数与费用边界的隔离实测；同源失败不自动重复付费。实际全源结果与未决项另列当日验收记录。
