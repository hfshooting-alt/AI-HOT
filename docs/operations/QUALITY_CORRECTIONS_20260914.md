# 分类与公司主体修正（2026-09-14）

用户确认：新闻分类与公司产品库是采集后的两个业务处理分支。独立开发者正式推出新AI产品，新闻保留release；公司归属不明只影响情报库，保留产品为归属待核实，不创建人名公司。

## 实现

- 新闻加工提示词升级v3，补充作品、活动、使用案例、预告的对照例。release必须返回输入中逐字存在的新发布证据；失败按已有单条隔离逻辑处理。明确预告/前瞻/预热经确定性规则改为general，成功缓存也应用该规则。
- 公司抽取提示词升级v8，区分company与product。product进入pendingEntities，网页显示产品名、归属待核实、原文链接；不计入公司数量。原始新闻分类不受该状态影响。
- 经本人介绍页核实，Simon Willison作为个人排除公司主体；其产品独立保留。Muse按本批次原始标题/摘要明确的“Meta个人AI助手”归属合并到Meta，证据记录为报道原始输入，不宣称官网核验。
- 国家/地区只使用公司自身事实，不继承整篇文章的地区标签；资料不足不猜测。
- 原文日期复核记录位于config/news_publication_review.json，以URL、标题与原始输入哈希共同匹配并保留原始日期、核验日期和证据。GPT-2原文为2019-02-14，当前上游收录记录隔离，不进入本批次公司更新。该记录是已核实个案，尚不能视为全部原文时效已自动核验。
